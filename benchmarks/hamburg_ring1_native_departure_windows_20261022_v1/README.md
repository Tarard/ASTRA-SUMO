## 数据与方法

范围保持 README 的 Binnenalster/Ring1，含 LSA 104、118、119、200、535。
网络、信号、车道权限、合法转向、车辆类型和三处路口的驾驶规则均未改变。
计数只读 SUMO 1.27.1 原生 E1 的 `nVehContrib`。
所有来源文件的校验值见[来源记录](timing-windows/source-sha256.json)。来源文件未改变。

先核对原入口方案和同车多字段备选的全部原生 E1 周期与逐车记录。
两套模型各保留 8640 次字段目标，模型车辆分别为 8640 和 8185 辆。
这里的合成车辆 ID 与目标配对不是现场车辆身份或真实 OD。

对车辆 $i$，用原生通知时刻 $t_{if}$ 计算其全部目标字段的时移区间。
目标时间窗为 $[a_{if},b_{if})$，原请求时刻为 $d_i$，边缘余量为 $g$。

$$
\Delta_i\in\bigcap_{f\in F_i}[a_{if}+g-t_{if},\ b_{if}-g-t_{if})
\cap[-900,900]\cap[-d_i,\infty).
$$

时移按 0.1 秒仿真步长取值，并保留原请求在步长内的相位。
请求时刻按原生毫秒精度取整。窗口右边界保持开区间。
在可接受区间内选择绝对值最小的时移。
缺少原生通过记录的车辆保持未知，不用自由流时间或零值替代。
缺少记录、共同区间为空、需要负发车时刻或超出本次时移限额的车辆均保留。

这些区间只使用冻结的通过延迟。它们不包含改变发车后的排队、插入或车道选择响应。
900 秒限额和 90 秒余量是本次试验的设置，不是物理约束。
即使模型车辆都落入目标窗口，也仍需重新运行 SUMO。
