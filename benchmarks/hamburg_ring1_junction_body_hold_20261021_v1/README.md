# 汉堡路口车身保持：初始化无碰撞，计数仍未达标

本次只检验一项驾驶假设：车辆从首次路口内观测到车尾驶出期间保持车道。
完整初始化小时为 **0 次碰撞、0 次传送**，原四辆涉事车均实际通过并完全驶出了对应路口。
全部 52 行原生 E1 可用，33 行一致，诊断 MAE 为 6.576923、最大绝对误差为 43。
仍有 147 辆未进入、145 辆在途。该结果不是有效零误差标定，也没有验证真实驾驶行为。

## 单项假设、依据与信息

父输入及失败对照为 [通行路线候选](../hamburg_ring1_through_route_coverage_20261021_v1/README.md)，碰撞过程见 [原生轨迹诊断](../hamburg_ring1_collision_trace_20261021_v1/README.md)。
本次保留全部 8640 辆车的路线、请求时刻、字段和时段，不修改网络、车道权限、信号输入或真实目标。
原合法转向及掉头仍在网络中，需求没有增加掉头或重复道路。

车辆首次被观察在内部车道后，设置原生 `laneChangeMode=512`。
当前内部车道剩余长度加车辆长度，给出车尾释放距离。进入下一内部车道时更新该距离。
只有检测断面保持和路口车身保持均结束，才恢复首次保持前的模式。
二者重叠时共用原模式，避免检测保持先结束就提前放开路口内换道。
默认行为不启用本次假设，只有本次声明的原生请求显式启用它。

输入为每步的原生车道、沿车道位置、累计距离和固定车长。
这些是仿真内驾驶状态，不是新增现场传感器信息。没有读取残差来改变模式、需求、路线或信号。
操作只包括模式 512 和原模式恢复，不发送换道、速度、位置、路线或信号命令。
原生安全约束保持，见 [SUMO 换道模式定义](https://sumo.dlr.de/docs/TraCI/Change_Vehicle_State.html#lane_change_mode_0xb6)。

Erdmann (2015), *SUMO’s Lane-changing model*，[DOI](https://doi.org/10.1007/978-3-319-15024-6_7)，说明瞬时换道、动机优先级和外部模式控制。
方法与实验阅读依据为 [DLR 作者稿](https://elib.dlr.de/102254/1/Springer-SUMOs_Lane_changing_model.pdf) 第 3、4.3、8、9、10.1 节。
**T2-方法可信，E2-实验有限**。本次采用模式控制接口，车尾释放范围为新探索假设，论文没有给定此规则。
它不是法律要求或现场驾驶规律，不保证所有交通状态安全，详见 [研究声明](../../docs/research/ring1-junction-body-hold-2026-10-21.md)。

使用仓库 SUMO/TraCI 1.27.1、步长 0.1 秒、seed 104。
仿真 0 为 2026-10-19 04:30 UTC，即当地 06:30 CEST，运行至 3600 秒、当地 07:30。
初始化请求为 1953 辆，未来主窗 6687 辆保留在原文件，不能算成本小时未进入。
全部在途车辆静止 300 秒即停止的检查保持启用。本次正常结束，无超时或全网静止停止。
原控制输入、Z.15 备选 A、200 施工阶段差异及原车道意图的未验证项继续保留。
OSM 感应信号的实际时序仍可随交通状态变化，相同输入文件不表示实际时序相同。

## 换道执行、原参与车辆与边界

共记录 20,799 个路口保持区间。保持生效期间没有原生横向换道。
仍有 21 次内部换道发生在保持开始之前，全部与首次观测前一个 0.1 秒步对应。
因此，进入路口当步的采样限制确实存在，不能声称完全禁止了所有内部换道。
详见 [换道日志核对](analysis/hold-audit.json) 和 [逐项时间核对](analysis/population-and-boundary-check.json)。

原四辆涉事车均到达对应路口，且在出口道路上观测到超过 5 m 的前进位置，确认车尾驶清。
四辆均在本小时到达终点，到达时刻分别为 2198.9、2027.8、3564.1、2493.1 秒，见 [逐车记录](analysis/original-participants.json)。
这排除了“原涉事车辆尚未到达，所以没有碰撞”的解释，但不代表原来两车同时相遇的状态被完全重复。
本次只改变一个驾驶假设，交通状态会随之改变，不能据此定位唯一 SUMO 源码缺陷或证明现场几何准确。

20,237 次保持显式释放，48 次在小时末仍有效。
另有 **514 次保持中车辆离开**，全部对应原边界出口 `27064186#0_0` 的正常 SUMO 到达。
该出口原长度为 0.1 m，车辆在位置 0.1 m 到达后移出模型。
这些不是碰撞、传送或未说明的车辆丢失，但也不证明车尾已显式驶清或原模式已恢复。
本次保留该既有边界假设，单独记录 [514 条到达](analysis/terminal-holds.json)，没有通过延长边界或改变需求来改善本次结果。
