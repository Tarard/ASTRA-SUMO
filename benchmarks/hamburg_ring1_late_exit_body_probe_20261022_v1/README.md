# 汉堡第三处路口：车尾驶离后再换道的小试验

本次只检验 `18653534` 出口的换道时机。
使用 [后期碰撞](../hamburg_ring1_late_collision_trace_20261021_v1/README.md) 两辆车的原路线，各生成 20 辆人工车。
两组共用网络、40 辆车、请求时刻、信号、车道意图和 13 行人工计数目标。
唯一驾驶差异是在原有两个路口保持范围中加入 `18653534`。
使用项目 SUMO/TraCI 1.27.1、0.1 秒步长、seed 104，运行至 900 秒。
全部在途车辆静止 300 秒的停止检查保持启用。

完整车道记录见 [成对检查](paired-check.json)，逐车字段对应见 [独立计数核对](identity-check.json)。

## 道路权限核对

原完整需求共有 1082 辆模型车计划通过该路口，分别来自三个道路方向。
它们可用的出口道路均长 38.38 m。
从 `139083723#0` 驶向下一道路 `234423652#1` 时，汽车只能使用出口车道 2。
车道 1 仅允许自行车。此前未筛选车型的连接表列出车道 1、2，不能直接作为汽车可用车道表。
本次没有改变道路权限，也没有让汽车使用自行车道。
[逐车型核对](passenger-route-audit.json) 是静态道路检查，不证明完整需求可以顺利换道或消散。

## 结果边界

这是稀疏人工车流的换道机制检验。两组都没有碰撞，不能用它宣称原后期碰撞已在完整需求下消除。
人工车复用原路线和类型，但请求时刻、车辆数及周围车流不同。
人工 13 行计数不替代原来的 130 个字段时段和 40 个派生站点时段。
它们全部保留在 [父完整运行](../hamburg_ring1_localized_junction_body_full_20261021_v1/README.md)。
第三处候选已单独开始完整需求检验。完整安全性、进入积压、真实计数残差及驾驶合理性尚未建立。
没有重新启用已造成 2.10 m 连接阻塞的全局保持。
