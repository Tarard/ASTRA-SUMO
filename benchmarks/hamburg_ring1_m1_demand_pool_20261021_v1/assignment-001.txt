Assignment 1: build the M1 route pool, offline only

No full-window simulation in this assignment.

1. Route rule

Each route passes each junction at most once.

An official multi-part controller (e.g. LSA200_part0–part3) counts as one junction. Consecutive parts within one traversal count as a single pass.
Turnarounds made within a single pass stay allowed. Opposite directions of a road stay allowed. No detour cap.
Splice exception. For a route that passes a junction twice, test the direct movement from its first entry approach to its last exit approach.
If that movement exists as a legal connection, exclude the route.
If it doesn’t, keep the route as a flagged round-the-block route.
Routes start and end only at declared boundaries.
2. Entries
No injection from the five entries still shorter than 7.5 m natively. Report them with zero assigned demand.
Add the primary-road prefix substitution (25866659#1 → 44532531) as a declared alternative entry. Keep the service prefix 963776077#0 as a labelled candidate.
Give each entry a declared inflow ceiling as a parameter, initially 900 veh/h per motor lane. Report which ceilings bind. This stops the solver from filling short side roads.
3. Structural checks

Report all of these:

per-field coverage: does each of the 13 fields keep at least one single-pass route?
lane-level response rank, with and without lane intent;
the vehicle-count lower bound (at most one field per junction per vehicle);
the number of routes excluded, flagged round-the-block routes, and remaining turnaround use per junction.

Report:
