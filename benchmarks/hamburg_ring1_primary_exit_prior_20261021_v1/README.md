# 汉堡 119 目的地先验：初始化改善，尚未完成标定

本次只修改 Z.12/Z.13 的目的地分配，保留全部车辆、出发时刻、检测字段、信号输入和车道权限。
完整初始化小时的未进入车辆由 364 降至 226，原生 E1 完整通过由 1471 增至 1548。
Z.15、Z.4 的通过数分别减少 40、24，仍有明显跨方向影响。
本候选未达到零误差，没有在本轮重新运行完整主观测窗。

## 为什么检验目的地

使用 [已完成的 K31/K2 初始化运行](../hamburg_ring1_z15_k2_routes_20261021_v1/README.md)，核对了 119 的 Z.11–Z.13 全部 978 辆初始化请求。
其中 445 辆到达、169 辆在途、364 辆未进入，均保留在分析中。
已完成行程和原生状态共同提供道路离开时刻，在途车辆的末区间只记录已耗时间下界。
较长耗时集中在检测后桥上及 LSA200 进口，不能只根据入口外排队认定入口本身的容量。
所检查的东向中间连接没有绑定独立信号。本项检查只覆盖所选东向路线。

当前 Z.12/Z.13 的全部 3452 辆模型车，都以 `19728446#0` 为终点。
它是 65.7 m 长的住宅道路，只有一条机动车道。
进口 `551303410` 的四条官方直行车道通往 `551303417`，后续道路 `186722706` 只有一条机动车道可以右转驶向该终点。
这是需要检验的目的地集中假设，不是已经排除所有其他影响的瓶颈证明。

原方案的原生排队输出中，`551303410` 只记录到车道 1、2。候选中出现了车道 3 的正排队长度记录，说明目的地变化伴随不同的车道使用。
排队输出没有记录某条车道，不等于该车道整个小时都没有车辆。
逐车道记录数是采样次数，不是车辆数，见 [排队采样](analysis/queue-sample-summary.json)。
断面保持的首次位置大多在进入检测道路后的一个仿真步内。
Z.13 中超过该距离界的记录，原方案为 2/341，本候选为 9/429。
这只约束已触发保持的车辆，不足以支持“普遍很晚才并入检测车道”的解释。
因此，本次没有增加提前途经点或放宽换道权限。

## 单项候选与假设

原路线池已有继续驶向 `142944538` 的合法路线。
该出口为主干路，长 262.534064 m，有两条机动车道。
新路线与原路线在 `186722706` 之前的道路序列相同，检测前自由流偏移也相同。
没有增加掉头、重复道路、重复物理路口或客户道路，也没有新增观测道路。

本次将既有入口等级权重用于出口份额代理：主干路每机动车道 900 veh/h，住宅道路每机动车道 200 veh/h。
两出口代理权重为 1800、200，即 9:1。
这是新的、明确声明的目的地先验，不是实测 OD 或现场通行能力，也不是论文直接给出的比例。
每个目标时段按最大余数法分配，平分时优先主干路，并交错安排两类目的地。

## 配对人工检验

两组使用相同 40 辆人工车、相同出发时刻和驾驶方式。
从仿真 100 秒开始，每 2 秒交替取一辆，覆盖三个既有来源与字段组合，结束于 900 秒。
原方案 40 辆均驶向住宅道路；候选中 36 辆驶向主干路、4 辆仍驶向住宅道路。
这个小样本是结构检验，不作为普通交通分布或容量估计。

两组都为 40 辆进入、40 辆到达，Z.12、Z.13 原生 E1 计数分别为 27、13。
每辆均完成指定字段通过一次，无其他字段通过或重复通过，碰撞、传送、丢弃、在途和未进入数量均为 0。
首辆驶出 LSA200 进口的时刻均为 268.8 秒，末辆由 542.6 秒提前到 455.3 秒。
道路前端离开时刻仅作诊断，没有替代 E1 的 `nVehContrib`。
人工目标与全部真实计数保持分开，见 [配对结果](analysis/paired-probe-summary.json)。

## 判断与未完成项

**已验证**：本次目的地变化影响了原生通过数量，检测后的排队不能只归因于入口。
初始化误差和进入数量改善，但其他方向退步，仍有大量车辆未进入。
**候选**：9:1 目的地份额，尚未取得主窗原生结果或真实 OD 证据。
**未完成**：主窗 130 个字段时段和 40 个派生站点时段的有效零误差标定、剩余入口等待和跨方向影响。

当前仍采用单字段车辆、单观测道路的限制，未检验原池中经其他观测道路但不重复道路的主干通行路线。
这项限制是当前模型假设，不是用户对合法路线的全部要求，也不能作为全体其他方案不可行的证明。
本轮不继续改份额或重跑完整时段。
现有车道意图、占位控制、200 施工阶段差异和几何候选的未验证项继续保留。
